# C++ Beginner Practice

I am a first-year BTech CSE student learning C++.
This repository contains my beginner practice programs using functions,
conditions, loops, and a menu-driven calculator.

## Programs
- Even or odd
- Largest of three numbers
- Calculator
- Grade checker
- Multiplication table
- Sum, factorial, reverse, and digit count
- Prime number check

## Run
Compile practice.cpp with a C++ compiler and run the resulting program.
